# % 채점학 · Percent Grading

**답안의 부분적 타당성, 근거, 불확실성을 보존하는 AI 채점 연구·개발 프로젝트입니다.**

[English](README.md) | [한국어](README.ko.md) | [영문 교재](book/Percent-Grading-Textbook.md)

제안자: **김유빈(Yubin Kim)**

## 왜 만들기 시작했는가

정답과 다른 답안에도 맞는 구성 요소, 유효한 관계, 특정 조건에서 성립하는 결론이 있을 수 있습니다. 하나의 정답·오답 판정만으로는 이러한 차이가 사라질 수 있습니다.

출발점은 A라는 답을 요구할 때 A만 인정해야 하느냐는 질문이었습니다. 이상화한 도형 분해에서는 다른 기호가 A의 획 일부를 공유할 수 있습니다. 그 부분은 설명할 가치가 있지만, 부분이 같다는 사실만으로 전체 기호가 A라는 뜻은 아닙니다.

이 프로젝트는 다음 질문을 공학적으로 다룹니다.

> 이 답안에서 무엇이 맞고, 무엇이 틀렸으며, 어떤 조건에서 성립하고, 무엇을 아직 판단하지 못했는가?

기존에도 부분점수와 분석적 평가 기준은 존재합니다. % 채점학은 AI를 이용해 더 많은 관련 관점을 적용하고, 판단 근거와 충돌을 검토 가능한 형태로 남기는 방법을 연구합니다.

## 무엇의 퍼센트인가

점수는 **명시한 평가 기준의 가중 충족도**입니다. 세계의 모든 이론에서 참인 비율, 정답일 확률, 사람의 지능을 뜻하지 않습니다.

| 평가 차원 | 확인하는 내용 |
|---|---|
| 구성 요소 | 필요한 대상과 속성이 있는가 |
| 관계 | 논리·인과·공간·시간의 연결이 맞는가 |
| 조건 | 가정과 적용 범위, 예외를 지키는가 |
| 목표 충족 | 문제에서 요구한 결과를 달성하는가 |

부분이 맞더라도 핵심 목표가 실패할 수 있습니다. 필수 기준을 통해 부분 인정과 전체 성공을 구분합니다.

## 기대하는 장점

| 기대 효과 | 설계 방법 | 검증할 사항 |
|---|---|---|
| 구체적인 학습 피드백 | 기준별 근거와 보완 방향 제공 | 실제 학습에 도움이 되는가 |
| 다른 표현의 정답 인정 | 의미와 대안 풀이 평가 | 모호한 답안을 과대평가하지 않는가 |
| 판단 검토와 이의 제기 | 인용·이유·기준 버전 기록 | 근거가 판단을 실제로 뒷받침하는가 |
| 다양한 관점의 적용 | 이론·평가 관점 등록 체계 | 비용 대비 품질이 향상되는가 |
| 불확실성 표시 | 평가 범위와 미판정 부분의 범위 제공 | 사용자가 수치를 올바르게 이해하는가 |

이 표는 검증하려는 기대 효과이며, 이미 측정된 성능을 뜻하지 않습니다.

## 작동 방식

1. 문제 목표, 가정, 참고 답안과 허용 가능한 대안을 정의합니다.
2. 평가 기준, 가중치, 점수 기준과 필수 조건을 고정합니다.
3. AI에 전달할 채점 요청을 생성합니다.
4. 답안 인용과 이유를 포함한 기준별 판단을 받습니다.
5. 입력을 검증하고 고정된 규칙으로 계산합니다.
6. 전체 점수보다 기준별 결과, 필수 실패, 평가 범위를 먼저 확인합니다.

장기적으로 여러 관점은 같은 평가 기준에 근거를 제공합니다. 관점 수가 늘어난다는 이유만으로 배점이 늘어나지 않습니다. 비슷한 이론 수천 개가 독립적인 증거 수천 개가 되는 것은 아니기 때문입니다.

‘모든 관점’은 확장 방향입니다. 실제 시스템은 어떤 관점을 검토했고 무엇이 남았는지 범위를 명시해야 합니다.

## 현재 기능

평가 요청 생성, JSON 검증, 인용문 일치 확인, 점수 집계, 필수 기준 처리와 판단 보류를 구현했습니다. 예제, 테스트, 영문 교재를 제공합니다.

AI API 자동 호출, 대규모 이론 검색, 여러 AI의 판단 충돌 조정은 후속 단계입니다. 사람이나 기존 채점 방식보다 정확하다는 실증 결과는 아직 없습니다. 포함된 판단 파일은 설명용 수기 예제입니다.

## 실행

Python 3.10 이상이 필요하며 핵심 프로그램은 외부 패키지를 사용하지 않습니다.

~~~text
python -m percent_grading prompt examples/osmosis.case.json
python -m percent_grading aggregate examples/osmosis.case.json examples/osmosis.judgments.json
python -m unittest discover -s tests -v
~~~

첫 명령의 출력을 선택한 AI에 전달하고, 반환된 JSON 객체만 UTF-8 파일로 저장합니다. 그 파일을 두 번째 명령의 판단 파일로 지정합니다.

삼투 예제는 판단된 기준의 충족도 약 **83.33%**, 평가 범위 **90%**, 미판정 기준에 따른 범위 **75–85%**를 보여 줍니다. 이는 수기 예제의 계산 결과입니다. 해당 범위는 AI 오판까지 포함한 통계적 신뢰구간이 아닙니다.
