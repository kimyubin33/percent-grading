# Changelog

## 0.5.0 - 2026-11-12

- Added a strict benchmark suite/result format, criterion expectations, within-task relations, development/holdout splits, and detailed failure and coverage reports.
- Added ten authored tasks and sixty cases with reproducible manual results that deliberately exercise errors and withheld outcomes; these are not live model performance measurements.
- Added bounded live experiment planning and batch execution, distinct fresh-repeat identities, persistent conservative attempt reservations, resume, and saved-result verification.
- Added a transport-independent versioned JSON service, opt-in live grading, a loopback-only authenticated HTTP adapter, and application-facing error envelopes.
- Added a dependency-free JavaScript client with TypeScript declarations, no automatic retries, and Rust/Node.js integration examples.
- Updated English/Korean introductions, technical guides, and textbook chapter 17.

The benchmark references and holdout split are authored fixtures, not independent educational validation. Application identity, production hosting, and account-wide spending controls remain outside the local adapter. No paid live-provider evaluation was performed for this release.

## 0.4.0 - 2026-11-12

- Added a real RelSpec/AHAA evidence-policy profile with claim coverage, conditions, inclusion and exclusion rules, origin thresholds, and context limits.
- Added frozen source dossiers, exact claim-to-source quotation checks, and declared support/counterevidence search records.
- Added two-provider source audits with categorical support, applicability, and eligibility reviews, immutable first-response records, resume, and replay.
- Derived explicit supported, contradicted, conflicted, insufficient, and hypothesis states; repeated origins and duplicate text cannot inflate independent support.
- Added opt-in deterministic grading gates: unresolved required evidence withholds affected settled awards even when answer judges agree.
- Preserved ordinary grading and 0.2/0.3 replay; reviewed evidence and unreviewed research packs cannot be combined in one grading request.
- Added evidence comparison and a versioned reassessment plan covering every declared cohort member without automatic API calls or overwritten results.
- Added synthetic evidence fixtures, an English evidence guide, bilingual introductions, and textbook chapter 16.
- Passed 123 local Rust tests, 16 legacy Python tests, formatting, Clippy, and a release build. The bundled CLI examples verify score withholding and a complete pending revision cohort without API calls.

The example reviews are manually authored protocol fixtures, not real provider outputs. Source text and search histories are supplied by the curator; the program does not fetch or authenticate their URLs. No paid live-provider evaluation was performed for this release. Software checks do not establish scientific truth or educational validity.

## 0.3.0 — 2026-11-12

- Added bounded Crossref bibliographic discovery with DOI metadata and verifiable snapshots.
- Added sourced catalogs with explicit assumptions, dimensions, hypotheses, and overlap groups.
- Added deterministic selection from the task before seeing the answer, with count and context-byte limits.
- Suppressed overlap groups and exact duplicate content without adding scoring weight.
- Bound selected research, catalog snapshots, and selection diagnostics into the grading run identity.
- Preserved replay of 0.2 records without rewriting their identities or results.
- Added an eight-perspective apple catalog, research guide, and textbook chapter 15.
- Passed 80 local Rust tests, formatting, and Clippy, including a 10,000-entry capacity test.

The live Crossref connection was unavailable in the local execution environment. CI includes a non-blocking public connectivity smoke check; inspect that step separately from the offline test results. No paid AI evaluations were performed. Discovery returns candidates for source inspection, not validated theories.

## 0.2.0 — 2026-11-12

The project now has a Rust executable that compiles an actual RelSpec/AHAA contract, calls exactly OpenAI and Claude, validates categorical evidence, and produces a deterministic score profile.

- Pinned and integrated the upstream AHAA compiler without changing its source.
- Added strict policy, criterion, anchor, and perspective records with cross-reference checks.
- Fixed all possible numeric awards before evaluation. Model responses cannot add score fields.
- Separated current fulfillment from future hypothesis quality.
- Preserved disagreement as ranges and review status instead of averaging.
- Added official structured-output API adapters with bounded requests and credential preflight.
- Added content-addressed input records, cached provider responses, interrupted-run resume, and offline replay.
- Added four manually authored apple examples and textbook chapter 14.
- Verified 48 Rust tests, formatting, Clippy, and the 16 legacy Python tests locally.

No live API accuracy or educational benefit is claimed. The fixture results are authored examples, and two agreeing models can still be wrong. Automatic theory retrieval and human adjudication remain planned.
